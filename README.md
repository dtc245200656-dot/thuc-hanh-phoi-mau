# Thuc hanh su dung mau sac trong trang web

Ma nguon dua tren bai mau Pra cua CodeGym.

- index.html: phien ban xanh duong theo de bai.
- green.html: phien ban don tong xanh la (buoc 8).
- style.css / style-green.css: CSS cho tung phien ban.
- fonts / images: tai nguyen goc, giu nguyen duong dan.
